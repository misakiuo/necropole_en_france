# Carte des nécropoles en Fance 🗺️

Dans cette page, vous trouverez une carte interactive et les données utilisées sur les nécropoles en France métropolitaine.

Les nécropoles nationales ont été créées par la loi du 29 décembre 1915 pour regrouper les corps des combattants « morts pour la France » avec des sépultures perpétuelles.

Grâce à cette carte, vous pouvez chercher la localisation des néclopoles, rechercher des néclopoles qui vous intéressent par le filtre voire aller avoir plus d'informations.
